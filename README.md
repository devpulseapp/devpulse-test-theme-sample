# DevPulse Marketplace test: Themes

**Temporary test fixture.** This repository holds a placeholder add-on for testing the DevPulse Marketplace, the in-app catalog that installs and updates published add-ons from signed releases. It will be deleted when the Marketplace goes live.

- `sample/`: placeholder.sample-theme, a small Theme with two colour themes, Sample Teal (dark) and Sample Sand (light). Their colours are made up for testing.
- Releases carry the packed add-on files and `SHA256SUMS`. The signed list that tells DevPulse about them lives in [devpulse-test-registry](https://github.com/devpulseapp/devpulse-test-registry).

The placeholder is built with the DevPulse Add-on SDK, which is not included here.
